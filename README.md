# Portfolio site source

This repository is deployed to **https://nageshnnazare.github.io**.

- **Source** lives here (`src/`)
- **Build** runs via [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) on push to `main`

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
